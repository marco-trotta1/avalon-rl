# Report design

The report serves a researcher who needs to locate a changed transition.
It shows the comparison path before the findings.
It keeps the interpretation beside the evidence limits.

The palette uses paper `#f6f8fc`, ink `#152246`, blue `#2147dc`, line `#d9e2f2`, red `#b42342`, and amber `#995100`.
Blue identifies navigation and evidence controls.
Red identifies errors.
Amber identifies incomplete evidence and warnings.
The report does not use green as the primary color.

The report uses locally available Avenir Next or Segoe UI.
Fingerprints use a local monospace font.
The layout follows a source-to-target path and a filterable findings table.
The path becomes vertical on a narrow screen.
Keyboard focus remains visible.
The report uses no automatic animation.
The design avoids decorative charts because the report contains discrete findings.
